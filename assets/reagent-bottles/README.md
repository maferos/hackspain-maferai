# Reagent jars & powders — procedural 3D kit

Plastic reagent jars, powder fills, loose powder piles, a weigh boat and a micro spatula
for the virtual perfumery lab. Everything is generated by `generate_reagent_jars.py`
(Blender 5.0+, also runs headless with the `bpy` pip wheel), so nothing here has a
third-party licence — it is all yours.

Real-world scale (metres), origin at the bottom-centre of every asset, glTF is +Y up.

## Files

| File | What |
|---|---|
| `reagent_jars_kit.blend` | Every asset, one collection each. Opens in Blender 5.0 / 5.1. |
| `reagent_jars_kit.glb` | All assets in one file (2.3 MB). |
| `glb/jar_<size>_hdpe.glb` | Opaque white HDPE jar, 6 sizes. |
| `glb/jar_<size>_pet.glb` | Clear PET jar (powder visible through the wall), 4 sizes. |
| `glb/powder_pile_vanillin.glb`, `glb/powder_pile_benzoin.glb` | Loose powder heaps, 36 mm and 28 mm across. |
| `glb/weigh_boat_45mm.glb` | Square polystyrene weighing dish with pour corner. |
| `glb/micro_spatula_180mm.glb` | Stainless micro spatula (flat blade + scoop). |
| `labels/<material>.png` | 1024×512 label textures. `powder_grain_normal.png` is the tiling grain normal map. |
| `preview.png` | Cycles render of the whole kit. |
| `generate_reagent_jars.py` | Rebuild / tweak everything: `blender -b -P generate_reagent_jars.py -- --out .` |

## Structure of a jar (per GLB)

```
jar_250ml_hdpe_Body      ← root, extras: asset, capacity_ml, material, powder, powder_cas
 ├─ jar_250ml_hdpe_Cap    separate object → unscrew / hide it
 ├─ jar_250ml_hdpe_Powder solid fill with a noisy top → scale Y to change the fill level
 └─ jar_250ml_hdpe_Label  200° wrap, UV 0-1 → swap the texture for any material
```

Materials (PBR metal/rough, all exported): `HDPE_White`, `PET_Clear` (transmission), `Cap_PP_White|Blue|Black`,
`Powder_<Material>` (base colour + grain normal map), `Label_<Material>`, `Polystyrene_White`, `Stainless_Steel`.

## Powders included (label + colour)

Vanillin (CAS 121-33-5) · Ethyl Maltol (4940-11-8) · Coumarin (91-64-5) · Musk Ketone (81-14-1) ·
Ambroxan (6790-58-5) · Benzoin Resinoid (9000-05-9).

To add a material: append a row to `POWDERS` in the script (name, CAS, RGB, fill fraction) and rerun.
Or, at runtime, change the `Powder_*` material's base colour and swap the label texture — one jar
model covers every raw material.

## Using in three.js / Unity / Unreal

- **three.js:** `GLTFLoader` — `PET_Clear` needs `MeshPhysicalMaterial` transmission (the loader sets it
  up from `KHR_materials_transmission`); enable `renderer.transmission` or use a transparent
  background pass.
- **Unity:** import with glTFast or UnityGLTF; PET jars use the URP/HDRP transparent surface.
- **Unreal:** native glTF import; set `PET_Clear` blend mode to *Translucent*.
