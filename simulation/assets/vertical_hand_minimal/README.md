# Minimal vertical hand

The hand of [`gripper-design/vertical_hand.html`](../../../gripper-design/vertical_hand.html)
as plain solids, ending at the black head under the UR flange: no arm, no bottle.
Generated by [`gripper-design/blend/build_vertical_hand.py`](../../../gripper-design/blend/build_vertical_hand.py)
(one module per subassembly: `cage.py`, `gripper.py`, `clamp.py`, `pipette.py`); do not edit these files by hand.

```bash
uv run --no-project --python 3.11 --with bpy --with mujoco python gripper-design/blend/build_vertical_hand.py
```

| File | What |
| --- | --- |
| `vertical_hand_minimal.blend` | Every part a passive rigid body with an exact BOX / CYLINDER shape (the pipette's three truncated cones a convex hull). Rings are box segments so their bores stay open. Empties `vertical_hand` (root), `jaw_P`, `jaw_N`, `clamp`, `pipette`. Shown closed on the 60 ml, the clamp parked back and high with the iris open (the only pose a bottle can come up in), pipette parked. |
| `vertical_hand_minimal.xml` | The same solids as MuJoCo geoms (all colliders). Jaws on slide joints coupled by an equality, `fingers_actuator` ctrl 0 open ... 255 shut, sensors `right/left_pad_force`, `finger_drive`, `right/left_finger` and site `pinch` named as the sensed Robotiq's, so `scripts/generate_rail_scene.py` (TOOL = 'vertical_hand') and `rail_kinematics.read_grip` use it unchanged. |
| `vertical_hand_minimal.png` | Workbench preview. |

Frame: +X from the arm to the bottle, Y across, Z up; the cradles' axis at z = 57.1 mm, the flange face at
z = 532 mm over x = -106 mm. On the arm it hangs flipped (180 degrees about X) with its flange face on the tool
frame, so the bottle's axis sits 106 mm in front of the tool axis and the cradles 475 mm out.

Not to be confused with [`../vertical_hand/`](../vertical_hand/README.md): that is the full rigged
hand, with the page's 21-step sequence, the bottle and the cap, for studying the uncap-and-pipette
cycle on its own. This one is the arm tool: the same shape as plain solids, wearing the Robotiq's
control and sensor interface so the rail arm can carry it without changing the pick pipeline.
