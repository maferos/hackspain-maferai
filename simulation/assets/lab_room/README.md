# lab_room

The perfumery / formulation lab around the `minihannover` bench, modelled on a
walkthrough video of the real lab (18/09/2026): a long, white, cleanroom-style room lit
evenly from above, with a library of amber raw-material bottles on the central bench.

Generated by [`scripts/generate_lab_room.py`](../../scripts/generate_lab_room.py); edit the
script and re-run it rather than editing `lab_room.xml` or `meshes/`.

```bash
python scripts/generate_lab_room.py
```

## Frame and layout

The bench's frame: origin on the floor at the bench centre, +X along the bench, +Z up.
Interior 14 x 5 x 3 m, x in [-8.5, 5.5], y in [-2.9, 2.1]. The entrance is at -X; walking
in, the right-hand wall is -Y.

| Zone | Where | What |
| --- | --- | --- |
| Shell | walls, floor, ceiling | Sandwich panels with 1.2 m joints, skirting, modular ceiling with LED panels and grilles (group 2), 11 soft lights |
| Glass partition | far end (x = 5.5) and right wall from x = 2.5 | Glass, aluminium mullions, two frosted bands; an office with desks and three stand-in staff beyond |
| Central bench | on `minihannover` | Glossy white worktop finish, under-bench units, gantry (4 modules x 4 shelves), splash glass, amber library, trays, beakers, tent cards, balance mats, platform scale |
| Wash zone / drying rack | far end of the bench | Induction hob, pot, carboy, wash bottles, funnel; wire drying rack with inverted glassware. The sink itself is `../sink/` |
| Right wall bench | x in [-5.0, 2.2] | Units with open bays, grey unit, microwave, overhead stirrer, stands, controller, hotplate, trays, boxes; kraft drums and blue carboys underneath; step stool |
| Entrance corner | x < -6 | L-counter with pot, sachets, papers; trolley; blue carboy; flammables cabinet; bin; red/navy rack |
| Instrument bench | left wall, x in [-6.6, -3.8] | Bench for `../gc_ms/` and `../uv_vis_nir/` (not in the video) |

Cameras: `entrance`, `aisle`, `library`, `wash`, `drying_rack`, `far_end`, `overview`
(prefixed `room_` once attached).

## Amber library

About 690 bottles: 3 row patterns of 21–23 bottles (two staggered rows), reused on all 32 shelf faces
(the +Y faces turned 180 degrees): one mesh each for glass, caps and labels. That keeps
the library at ~100 geoms. The bottles are low-poly lathes (~400 ml); the detailed
kit bottles (`../amber_bottles/`) are used only for the loose, movable ones.

## Use

```xml
<asset><model name="lab_room" file="../assets/lab_room/lab_room.xml"/></asset>
...
<attach model="lab_room" body="lab_room" prefix="room_"/>
```

Everything is welded to the world. Decor is visual only (`contype="0"`); benches, counters,
gantry, walls and glass keep box colliders.
