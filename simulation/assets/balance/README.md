# balance

An analytical balance with a glass draft shield, **0.210 m (X) × 0.299 m (Y) × 0.311 m (Z)**,
keypad and display on the -Y side.

Everything here is generated by [`tools/convert_dae.py`](../../tools/convert_dae.py) from the
SketchUp COLLADA export in [`../../../assets/analytical-balance/`](../../../assets/analytical-balance/);
re-run it rather than editing the files:

```bash
python tools/convert_dae.py ../assets/analytical-balance/model.dae --name balance --out assets/balance \
    --skip 7 8 9 10 --skip-material material_0 --mass 6
```

- `--skip 7 8 9 10` drops a loose flat part (about 17 cm long) lying next to the balance in the source model.
- `--skip-material material_0` drops SketchUp's back faces. They are a coincident copy of every face in the
  default back colour and would z-fight with the front faces.
- `--mass 6` puts a realistic 6 kg on the collision box. The visual meshes carry no mass.

`--list` prints the geometry instances with their bounds. The file is in inches
(`<unit meter="0.0254">`) and Z-up; the converter reads both from the file.

The draft shield uses SketchUp's `Translucent_Glass_Tinted` material. Its texture is ignored
(the converter only takes flat colours), so it renders as grey glass with alpha 0.48.

## Frame convention

Origin at the bottom, centred in X and Y, +Z up. Place it on the surface it stands on.

## Files

| File | Purpose |
| --- | --- |
| `balance.xml` | MJCF: mesh visuals (no collision, no mass) + one 6 kg box collider |
| `part_00.obj` … `part_10.obj` | One mesh per material, metres |

`balance.xml` has a single `balance` body, so attach it to place several:

```xml
<asset><model name="balance" file="../assets/balance/balance.xml"/></asset>
...
<frame pos="1.5 0 0.9"><attach model="balance" body="balance" prefix="right_"/></frame>
```

See `models/minihannover_scene.xml`.
