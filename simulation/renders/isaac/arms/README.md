# Robot arm eye-in-hand renders — open-hannover

Isaac Sim 4.5 RTX renders of three candidate manipulator arms placed on the
`minihannover_open` bench, each posed hand-down over the labelled-bottle field in
3 positions, with an **eye-in-hand camera mounted just below the hand** looking
straight down.

Generated by [`scripts/arm_pose_render.py`](../../../scripts/arm_pose_render.py)
on a RunPod A40 (driver 570). The arm USDs are referenced live from the
Omniverse content server (Franka/UR/Kinova), not baked into the MuJoCo scene.

## Layout

- `eih/<arm>_posN.png` — eye-in-hand camera (the manipulation view)
- `general/<arm>_posN.png` — overview camera with the arm in place
- `montage_eih.png`, `montage_general.png` — 3×3 comparison grids

## Arms compared

| Arm | Config (IsaacLab-mlx) | Eye-in-hand verdict |
| --- | --- | --- |
| **Franka Panda** | `FRANKA_PANDA_HIGH_PD_CFG` | ✅ Recommended — clean top-down, compact `panda_hand`, best supported |
| **Kinova Gen3** | `KINOVA_GEN3_N7_CFG` | ✅ Strong alternative — slim wrist, no self-occlusion |
| **UR10e** | `UR10_CFG` (ur10e USD) | ⚠️ Bulky wrist fills ~40 % of the eye-in-hand frame |

## How the camera is placed

The MuJoCo scene has no arm, so the arm is added at render time. After posing
the articulation (gravity disabled so the pose holds), the script reads the
**actual hand world position** and drops the eye-in-hand camera just below it,
clamped to ~0.7 m above the bench so it always frames a cluster of bottles
rather than a single cap. This decouples the camera from the exact wrist tilt.

See [`../../../runpod-isaac.md`](../../../runpod-isaac.md) for the full pipeline.
